# 当前版本操作说明

适用对象：没有计算机基础的现场操作工、装配工、试验辅助人员。

适用范围：当前版本的键盘遥控测试流程。

本说明只讲现在已经验证可用的流程：

- 键盘在 GCS 电脑上按
- 指令通过 `gcs_server` 发到香橙派
- 香橙派上的 `pwm_control_program` 计算 PWM 输出

本说明优先于旧的本地键盘遥控文档。当前版本不要在香橙派本地窗口里直接按 `W/A/S/D` 控机器人。

## 1. 这份说明能做什么

这份说明教你做两件事：

1. 不接真实推进器，只做安全测试，确认程序能收到控制指令。
2. 在满足安全条件时，做真实设备的手动遥控测试。

重要说明：

- 当前手动模式不依赖导航。
- 当前自动模式依赖导航。
- 如果只是做手动遥控测试，请始终使用手动模式，不要切到自动模式。

## 2. 先记住这几个词

- `香橙派`：机器人上的主控小电脑。
- `GCS`：操作员手里的电脑。
- `终端`：黑色命令窗口。
- `手动模式`：人按键，机器人按人给的方向动。
- `急停`：立刻进入安全状态，停止输出。
- `解锁`：允许推进器输出。
- `测试模式`：命令里带 `--pwm-dummy`，只打印结果，不会真正驱动推进器。

## 3. 安全要求

在你没有经过负责人允许之前，只能先做测试模式。

第一次测试或排错时，必须满足下面要求：

- 先用 `--pwm-dummy` 测试模式。
- 如果要接真实推进器，先拆桨或把机器人固定住。
- 旁边必须有人能随时按急停。
- 任何时候只要觉得不对，先按 `Space` 急停。

## 4. 你需要准备什么

- 一台香橙派，程序已经编译好。
- 一台 GCS 电脑。
- 两台机器在同一个局域网里。
- 知道香橙派的 IP 地址。

如果你不知道香橙派 IP，请找技术员先确认，不要自己猜。

## 5. 当前推荐使用方法

当前推荐流程一共开 3 个终端窗口：

- 香橙派窗口 A：启动 `gcs_server`
- 香橙派窗口 B：启动 `pwm_control_program`
- GCS 电脑窗口 C：启动键盘控制界面

如果是第一次上手，先做“测试模式”。

## 6. 第一次测试：安全测试模式

### 6.1 在香橙派上打开窗口 A

复制下面命令：

```bash
cd /home/wys/orangepi/UnderwaterRobotSystem/OrangePi_STM32_for_ROV/build/bin
./gcs_server
```

正常时会看到类似字样：

```text
[gcs_server] running. Ctrl+C to quit.
```

看到这行，说明窗口 A 正常。

### 6.2 在香橙派上打开窗口 B

复制下面命令：

```bash
cd /home/wys/orangepi/UnderwaterRobotSystem/OrangePi_STM32_for_ROV/build/bin
./pwm_control_program --no-teleop --pwm-dummy --pwm-dummy-print
```

这是测试模式。

它的特点是：

- 会计算 PWM
- 会打印 PWM
- 不会真的驱动推进器

正常时会看到类似字样：

```text
[INFO] pwm_control_program starting...
[ControlLoop] starting ...
```

### 6.3 在 GCS 电脑上打开窗口 C

把下面命令里的 `<香橙派IP>` 换成真实 IP。

```bash
cd /home/wys/orangepi/UnderWaterRobotGCS
UROGCS_ROV_IP=<香橙派IP> PYTHONPATH=src python -m urogcs.app.tui.tui_main
```

如果 GCS 电脑就是香橙派本机，可以把 `<香橙派IP>` 写成 `127.0.0.1`。

## 7. 键盘怎么按

连接成功后，严格按这个顺序操作：

1. 按 `1`
2. 按 `m`
3. 按 `,`
4. 再按方向键

含义如下：

- `1`：切到手动模式
- `m`：清急停并回中
- `,`：解锁

常用运动键：

- `W/S`：前进 / 后退
- `A/D`：左移 / 右移
- `Q/E`：左转 / 右转
- `H/G`：上浮 / 下潜
- `R/T`：横滚
- `F/V`：俯仰

停止和退出：

- `.`：上锁
- `Space`：急停
- `Ctrl+C` 或 `Esc`：退出 GCS 键盘界面

不要做的事情：

- 不要按 `2` 切自动模式做无导航测试
- 不要跳过 `m` 和 `,`
- 不要在香橙派窗口里直接敲控制键

## 8. 怎么判断程序有没有正常工作

### 8.1 测试模式下

看香橙派窗口 B。

如果窗口 B 一直显示：

```text
duty=7.5%,7.5%,7.5%,7.5%,...
```

说明当前还是中位，没有真正收到有效运动指令。

如果你按了方向键后，窗口 B 出现类似：

```text
duty=8.5%,9.5%,8.5%,9.5%,7.5%,7.5%,7.5%,7.5%
```

说明程序已经收到控制命令，并且已经计算出了 PWM 变化。

这就说明链路是通的。

### 8.2 真实设备模式下

如果不用 `--pwm-dummy`，那么按键后机器人应该有实际动作。

如果没有动作，但测试模式能看到 PWM 变化，说明软件链路大概率正常，应继续检查：

- 推进器接线
- 电源
- STM32
- 机械安装

## 9. 真实设备模式怎么启动

只有在负责人允许、并且已经先完成测试模式后，才可以执行这一步。

当前更推荐的真实联调入口不是手工单独敲 `pwm_control_program`，而是走 supervisor：

```bash
cd /home/wys/orangepi/UnderwaterRobotSystem/UnderwaterRobotSystem
REAL_PWM=1 bash tools/supervisor/run_local_teleop_smoke.sh up
python3 tools/supervisor/phase0_supervisor.py status --json
```

至少要确认：

- `pwm_backend=stm32`
- `real_pwm=1`
- `pwm_control_program` 的命令行里没有 `--pwm-dummy`

确认这些之前，不要把“窗口里有 PWM 变化”解释成“STM32 已收到 PWM”。

香橙派窗口 B 改成下面命令：

```bash
cd /home/wys/orangepi/UnderwaterRobotSystem/OrangePi_STM32_for_ROV/build/bin
./pwm_control_program --no-teleop
```

注意：

- 这时不要带 `--pwm-dummy`
- 不要带 `--no-gcs`
- 建议现场仍保留一人专门盯着急停

## 10. 关机顺序

每次结束时，按下面顺序做：

1. 松开所有运动键
2. 按 `.`
3. 按 `Space`
4. 关闭 GCS 窗口
5. 在香橙派窗口 B 按 `Ctrl+C`
6. 在香橙派窗口 A 按 `Ctrl+C`

不要直接拔电。

## 11. 常见问题处理

### 问题 1：GCS 窗口打不开，或者一直连不上

先检查下面 4 件事：

1. `gcs_server` 是否已经在香橙派窗口 A 正常运行
2. 香橙派 IP 是否填对
3. 两台机器是否在同一个网络
4. 香橙派窗口 A 有没有报错后退出

如果窗口 A 已经退出，就重新执行第 6.1 步。

### 问题 2：按键了，但是没有任何反应

按下面顺序检查：

1. 先确认 GCS 窗口现在是激活状态，不要让输入法焦点跑到别的窗口
2. 确认已经按过 `1`
3. 确认已经按过 `m`
4. 确认已经按过 `,`
5. 确认香橙派窗口 B 不是用 `--no-gcs` 启动的

如果以上都做了，还是没反应，就先全部退出，再重新从第 6 步开始。

### 问题 3：窗口 B 一直只有 `7.5%`

这通常表示下面几种情况之一：

- 还没有解锁
- 还没有真正按下方向键
- GCS 没有连上
- 当前处于急停状态

处理方法：

1. 按 `Space` 一次，确认急停状态
2. 按 `m`
3. 按 `,`
4. 再按一次方向键

### 问题 4：看到导航报错，心里不确定能不能继续

如果你现在做的是手动模式测试，并且已经按了 `1` 进入手动模式，那么看到下面这些情况通常不影响本次手动测试：

- `nav_valid=0`
- `nav_stale=1`
- `nav_fault_code` 不是 0

原因是当前版本的手动模式不依赖导航。

但如果你切到了自动模式，就不能忽略这些问题。

### 问题 5：程序突然退出了

先不要反复乱点。

按这个顺序处理：

1. 先确认机器人已经停住
2. 关闭另外两个窗口
3. 从第 6 步重新开始
4. 如果连续两次都退出，把报错内容拍照发给技术员

### 问题 6：机器人动作不对，或者怀疑有危险

立刻做下面动作：

1. 按 `Space`
2. 按 `.`
3. 松开所有键
4. 如仍不放心，直接在香橙派窗口 B 按 `Ctrl+C`

先保安全，不要先找原因。

## 12. 班组长或维修员的额外检查方法

如果你需要证明“软件确实已经把 PWM 算出来了”，在测试模式跑完以后，可以查看下面两个日志文件：

```text
/home/wys/orangepi/logs/control/
/home/wys/orangepi/logs/pwm/
```

判断方法非常简单：

- `logs/control/` 里如果出现 `armed=1`，说明已经解锁
- `logs/pwm/` 里如果出现不是 `7.5` 的值，说明 PWM 已经变化

例如下面这种就表示程序已经在输出变化值：

```text
8.5000,9.5000,8.5000,9.5000,7.5000,7.5000,7.5000,7.5000
```

## 13. 一句话记住

当前版本的正确使用方法是：

先开 `gcs_server`，再开 `pwm_control_program`，最后在 GCS 电脑上打开键盘界面；测试时先用 `--pwm-dummy`，按 `1 -> m -> , -> 方向键`，有问题先按 `Space`。
